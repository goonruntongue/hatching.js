hatching.js

カードをクリックすると、そのハッチングを作る jQuery コードを表示してコピーできます。

グラデーション

左は濃く、右は薄い斜線

-45°

0°

水平ハッチ

画像の輪郭にも

$('.hatch-image').hatching({
  color: '#202020', angle: '150deg',
  width: '1px', gap: '6px',
  offsetX: '12px', offsetY: '16px'
});
